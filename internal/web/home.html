02 — Setup

Add a provider key (optional)

GitHub usually sends you here right after you install. If you closed that tab, open Setup and enter your installation ID — then pick Groq, OpenAI, Claude, Gemini, or Grok and paste the key.

  1. Install DiffSense on the repositories you want reviewed.
  2. Find the installation ID in the GitHub URL: Settings → Applications → DiffSense AI. The number at the end of github.com/settings/installations/12345678 is the ID.
  3. Paste the ID below, choose a provider, and save your API key. Leave it blank to stay on the free tier.

No ID yet? Install the app first — GitHub redirects to Setup automatically.
